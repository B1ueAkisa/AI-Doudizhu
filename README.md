2. **⚖️ 确定性本地代码裁判**：

3. **🎙️ 全明星 AI 毒舌复盘解说席**：

4. **🎬 电竞级演播室双屏对称架構**：

## 🚀 快速上手与运行

### 1. 环境准备
* Python 3.10+
* （可选）安装录屏依赖：`pip install playwright edge-tts`

### 2. 配置 API Key
复制密钥模板并重命名为 `api_keys.env`：
```bash
cp api_keys.env.example api_keys.env
```
填入你的智谱（Zhipu）或硅基流动（SiliconFlow）API 密钥（绝不要提交至代码仓库！）。

### 3. 一键启动
* **Windows 用户**：直接双击运行 **`启动竞技场.bat`**。
* **命令行启动**：
  ```bash
  python server.py
  ```
服务将在本地 `http://127.0.0.1:8888` 启动：
* **实时对局竞技台**：[http://127.0.0.1:8888](http://127.0.0.1:8888)
* **赛后复盘演播室**：[http://127.0.0.1:8888/replay.html?auto=1](http://127.0.0.1:8888/replay.html?auto=1)
* **导播视频大赏**：[http://127.0.0.1:8888/video_showcase.html](http://127.0.0.1:8888/video_showcase.html)
